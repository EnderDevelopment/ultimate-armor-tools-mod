# Ultimate Armor Tools Mod

Ultimate armor, tools, and weapons for Minecraft Fabric

## Features

- Ultimate Armor set (Helmet, Chestplate, Leggings, Boots)
- Ultimate Tools (Pickaxe, Axe, Shovel, Hoe)
- Ultimate Sword

## Requirements

- Minecraft 1.21.4
- Fabric Loader 0.16.5 or later
- Fabric API

## Installation

1. Download the mod JAR file from the [releases page](https://github.com/EnderDevelopment/ultimate-armor-tools-mod/releases).
2. Place the JAR file in your `mods` folder.
3. Launch Minecraft with the Fabric profile.

## Usage

1. Craft the Ultimate Armor set by combining Diamond Armor with special materials.
2. Craft the Ultimate Tools by combining Diamond Tools with special materials.
3. Craft the Ultimate Sword by combining Diamond Swords with special materials.

## Configuration

The mod does not have a configuration file. All items are registered with default settings.
